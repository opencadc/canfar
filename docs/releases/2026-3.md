# CANFAR Science Platform Release 2026.3
## Oct 14, 2026

!!! success "CSP 2026.3"

```

### **✨ New Features**
- Science Portal UX refresh.
- Session ID included in the title for Web Terminal sessions.
- When available, the Science Portal displays improved metrics for the platform, for users, and for sessions.
- Shared memory is available across all Session types through `/dev/shm`.

### **🐍 Python Client & CLI Improvements**
- Improved node selection configuration.
- Improved authentication when switching between SRCNet nodes.

### 🐛 Platform Fixes
- **Desktop Sessions**
    - Fixed race condition that caused the Astro Software menu to build incorrectly.
    - Address issue where older CASA versions were failing to start.
    - Desktop browser restored.
- **Science Portal** — clearer error when a user is not authorized to launch Sessions.
- **CARTA** — cookie length no longer blocks access to CARTA Sessions.

### ⚙️ Technical Changes
- New internal metrics microservice that can connect to metrics collectors.
- Consistent and enhanced job labelling for better metrics collection.
- Registry lookup failover improved; non-responsive servers no longer stall discovery on timeouts.

### 📦 Deployment Notes
- Helm charts accept custom annotations.
- CephFS `/arc` migration. **TODO:** user-facing schedule and remaining operator steps.
- **posix-mapper** — fixed a caching issue that could make groups collide.  New Keycloak-based version of posix-mapper expected in CanfarSP 2026.4.
- For updated deployment instructions, refer to the [OpenCADC Deployments repository](https://github.com/opencadc/deployments).
```
