# Code of Conduct

CANFAR follows the [Contributor Covenant Code of Conduct](https://github.com/opencadc/canfar/blob/main/CODE_OF_CONDUCT.md).
It applies to project discussions, issues, pull requests, documentation, and
community events.

Report harassment or other unacceptable behaviour privately to
`shiny.brar@nrc-cnrc.gc.ca`. Reports are reviewed fairly and confidentially.

See the [full code of conduct](https://github.com/opencadc/canfar/blob/main/CODE_OF_CONDUCT.md)
for the community standards and enforcement process.
